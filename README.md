# Work Dashboard Shell

Kerangka awal dashboard kerja. Belum berisi fitur bisnis.

## Jalankan
1. Ekstrak ZIP.
2. Buka folder di VS Code.
3. Jalankan `npm install`.
4. Jalankan `npm run dev`.

Struktur awal:
- Sidebar
- Topbar
- Main content
- Panel/card kosong
- Responsive desktop/tablet/mobile

Fitur berikutnya bisa ditambahkan tanpa mengubah kerangka utama.
